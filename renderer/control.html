Mobile Browser Setup
Apple Safari (iOS / iPhone)
1. Scan QR code with the iOS Camera app.
2. Tap Show Details → visit this website → Visit Website.
3. Tap Start Camera and tap Allow.
Google Chrome (Android)
1. Scan QR code or enter camera link in Chrome.
2. Tap Advanced → Proceed to [IP] (unsafe).
3. Tap Allow when prompted for camera access.
Connection Checklist
  • Computer and phone must be on the same Wi-Fi network.
  • Avoid Guest Wi-Fi networks with AP client isolation.
  • Ensure firewall allows incoming connections on ports 9211–9299.
