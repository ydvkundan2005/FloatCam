Mobile Browser Connection
📱 Apple Safari (iOS)
1. Scan QR code or visit HTTPS link.
2. Tap Show Details → visit this website → Visit Website.
3. Tap Start Camera and select Allow.
🤖 Google Chrome (Android)
1. Open the camera link.
2. Tap Advanced → Proceed to [IP] (unsafe).
3. Allow camera permissions when prompted.
Network Checklist
  • Both Mac and Phone must be on the same Wi-Fi network.
  • Avoid Public / Guest Wi-Fi with client isolation.
  • Ensure Mac Firewall allows incoming connections on port 9211.
